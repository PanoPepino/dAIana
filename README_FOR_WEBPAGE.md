# dAIana

Python · Typer · Rich · Language model APIs · LaTeX · CSV
<!-- SHARED:END -->

<!-- WEBPAGE:START -->
A command-line tool that uses language model APIs to tailor
modular LaTeX CVs and cover letters to job postings.

Users supply their own written document modules. dAIana
processes job information, selects relevant content and
compiles tailored PDF documents.

Users can review and edit generated fields before compilation.
The tool also provides CSV-based application tracking and
commands for recording professional contacts.
<!-- WEBPAGE:END -->
